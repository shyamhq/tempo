why now

Coding got cheap. Drift got expensive.

A coding agent will generate two thousand lines before lunch. The hard part isn't writing code anymore — it's deciding what to build, and agreeing on it, before the agent sprints off in the wrong direction. You find out in the diff. Tempo is where the decision happens first.

questions

The honest answers.

Do I need to install anything?

Only if you want the Local agent — that's your own Claude Code. The Hosted agent needs nothing on your machine.

Which coding tools does the Plan work with?

Any of them. The Plan is plain markdown — take it into Claude Code, Cursor, Windsurf, or your own pipeline.

Where does the agent run, and is my code safe?

Local stays on your machine. Hosted boots an isolated VM with egress locked to exactly what it needs, then tears down. Either way, nothing persists — your code stays your code.

Is it just for big teams?

No. Teams get shared Threads and @mentions; solo devs get an agent that plans the right thing before a three-hour run goes sideways.
